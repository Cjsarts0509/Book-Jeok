북적북적 서버(오라클) SSH 접속 설정 — 관리자용
==================================================

【이런 오류가 날 때】
  WARNING: UNPROTECTED PRIVATE KEY FILE!
  ... bad permissions ... Permission denied (publickey)

【원인 (한 줄)】
Windows 의 ssh 는 "나 말고 다른 계정도 읽을 수 있는" 키 파일을 쓰지 않습니다.
키 파일을 다른 폴더 · USB · 다른 PC 로 복사하면 새 폴더의 권한(Users · Everyone 등)을
물려받기 때문에, 키 하나를 여기저기 옮겨 쓰면 언제든 다시 막힙니다.

【근본 해결 = PC 마다 자기 키】
- PC 마다 키를 따로 만들어 그 PC 의 %USERPROFILE%\.ssh 에만 둡니다 (옮기지 않음).
- 서버에는 각 PC 의 "공개키"(.pub, 남에게 보여도 되는 쪽)만 등록합니다.
- 접속 정보는 .ssh\config 에 "bookjeok" 이름으로 적어 두어, 어느 PC 든  ssh bookjeok  한 줄로 접속합니다.
- PC 를 잃어버리거나 바꾸면 서버에서 그 PC 키 한 줄만 지우면 됩니다.

【사용 방법 — PC 마다 한 번】
1. 압축을 풀고 bookjeok-ssh.bat 더블클릭 (관리자 권한 필요 없음)
   - "Windows의 PC 보호" 파란 창이 뜨면 → 추가 정보 → 실행
2. 1 (이 PC 전용 키 만들기 + 서버 등록) → Enter
   - 암호(passphrase)를 물으면: Enter 두 번 = 암호 없이 / 암호 입력 = 접속 때마다 암호
3. 서버 등록 방법을 고릅니다.
   1) 지금 접속되는 예전 키 파일이 이 PC 에 있다 → 파일 위치를 넣으면(끌어다 놓기 가능) 자동 등록
   2) 없다 → 화면에 나온 한 줄(클립보드에 복사됨)을, 다른 PC 에서 서버에 접속한 창에 붙여 넣기
4. "[성공]" 이 나오면 끝. 이제 PowerShell 에서  ssh bookjeok

【메뉴】
  1  이 PC 전용 키 만들기 + 서버 등록 (다시 실행해도 안전 — 있는 키는 그대로 씀)
  2  상태 확인 · 막힌 원인 보기 (예전 키 파일을 넣으면 어느 폴더 권한 때문인지 알려 줌)
  3  키 파일 권한 고치기 (.ssh 안의 키 전부)
  4  예전 키 파일 그대로 쓰기 (임시 — .ssh 로 복사해 잠그고 bookjeok 설정)
  ※ 원본 키 파일(바탕화면 등)은 읽기만 하고 바꾸지 않습니다.

【서버에서 키 관리 (ssh bookjeok 으로 접속한 뒤)】
  등록된 키 보기 (PC 이름이 끝에 붙어 있음):
    ssh-keygen -lf ~/.ssh/authorized_keys
  어떤 PC 키 빼기 (예: home-laptop):
    cp ~/.ssh/authorized_keys ~/.ssh/authorized_keys.bak-$(date +%F) && sed -i '/bookjeok-home-laptop-/d' ~/.ssh/authorized_keys
  ⚠ 지금 쓰는 PC 의 키를 빼면 그 PC 는 바로 못 들어옵니다. 지운 뒤 새 창에서 접속을 꼭 확인하세요.

【예전 공용 키(오라클 콘솔에서 받은 .key) 정리 — 선택】
모든 PC 가 자기 키로 접속되는 것을 확인한 뒤에만:
  1) 위 "등록된 키 보기" 에서 PC 이름이 없는 줄(오라클 콘솔에서 넣은 키)을 확인
  2) 그 키 파일은 지우지 말고 USB · 비밀번호 관리자 등 안전한 곳에 비상용으로 보관
     (모든 PC 키를 잃어도 이 키로 들어와 다시 등록할 수 있음)
  서버에서 빼고 싶다면 백업 후 해당 줄만 지우되, 반드시 다른 PC 로 접속되는지 먼저 확인하세요.
