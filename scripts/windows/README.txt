북적북적이 느릴 때 (KT 인터넷) — 사용 안내
==================================================

【이런 분께 필요합니다】
KT 인터넷을 쓰는 PC에서 북적북적이 유난히 느린 경우.
(같은 시간에 휴대폰이나 다른 회선에서는 빠르다면 이 경우입니다.)

【원인 (한 줄)】
KT 인터넷이 북적북적이 쓰는 Cloudflare 주소로 갈 때 서울이 아닌 미국 쪽으로
돌아가 많이 느려집니다. 서버나 PC 고장이 아닙니다.
이 프로그램은 이 PC만 서울 입구로 접속하도록 고정합니다.

【사용 방법】
1. 받은 압축 파일을 먼저 "압축 풀기" 하세요. (압축 안에서 바로 실행하면 안 됩니다)
2. bookjeok-fast.bat 을 더블클릭하세요.
   - "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → 예
   - "Windows의 PC 보호" 파란 창이 뜨면 → 추가 정보 → 실행
3. 화면의 메뉴에서 1 (적용) 을 입력하고 Enter.
   "적용 완료"와 함께 "거점 서울(ICN)"이 나오면 성공입니다.
4. 브라우저를 완전히 닫았다가 다시 여세요.

【원래대로 되돌리기】
bookjeok-fast.bat 실행 → 2 (되돌리기) → Enter.
언제든 되돌릴 수 있고, 적용 전 hosts 파일은 자동으로 백업됩니다.

【적용했는데도 느리다면】
- 브라우저 설정에서 "보안 DNS"를 꺼 주세요. (웨일·크롬: 설정 → 개인정보 보호 및 보안 → 보안 → 보안 DNS 사용 끄기)
- 그래도 느리면 프로그램을 다시 실행해 3 (상태 확인) 화면을 관리자에게 보내 주세요.

【알아 두실 점】
- 이 PC에만 적용됩니다. PC마다 한 번씩 실행해야 합니다.
- 언젠가 다시 느려지거나 접속이 안 되면, 실행해서 1 (적용)을 다시 하거나 2 (되돌리기) 하세요.
- 바꾸는 것은 Windows의 hosts 파일에 북적북적 주소 두 줄을 넣는 것뿐입니다.

【Mac 사용자】
터미널에서 아래 한 줄 실행 (되돌리기는 /etc/hosts 에서 bookjeok-fast 줄 삭제):
  printf '104.16.0.1 bookjeok.cjs0509.xyz # bookjeok-fast\n104.16.0.1 bookjeok-api.cjs0509.xyz # bookjeok-fast\n' | sudo tee -a /etc/hosts
